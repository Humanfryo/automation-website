## ACCESSIBILITY REQUIREMENTS (WCAG 2.2 Compliance)

### **Must-Haves** (Hari is an accessibility specialist - this is critical!)
1. **Color Contrast**: 
   - Text-to-background contrast ratio ≥ 4.5:1 (normal text)
   - Large text ≥ 3:1
   - Test with WebAIM Contrast Checker

2. **Keyboard Navigation**:
   - All interactive elements (buttons, links, forms) must be keyboard accessible
   - Visible focus indicators (outline or ring on focus)
   - Tab order follows logical reading order

3. **Screen Reader Support**:
   - Semantic HTML (nav, main, section, article tags)
   - Alt text for all images/icons
   - ARIA labels where needed (hamburger menus, modals)

4. **Form Accessibility**:
   - Label elements properly linked to inputs
   - Error messages announced to screen readers
   - Required fields marked with aria-required

5. **Video/Media**:
   - Captions or transcripts for demo videos (optional but recommended)
   - Accessible video player controls

6. **Motion Sensitivity**:
   - Respect `prefers-reduced-motion` media query
   - Disable animations for users who request it
